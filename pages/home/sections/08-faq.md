## What is Pharaonic?

Pharaonic is an open-source collection of {stats.packages} Laravel, Livewire, Filament and PHP packages, founded in 2020 by Moamen Eltouny (Raggi). Each package solves one common problem (files, images, slugs, translations, settings, Hijri dates, and more), so you can finish your project faster with less code.

## Are all packages free to use?

Yes. Every Pharaonic package is free and open source under {stats.licenseText}, so you can use it in personal and commercial projects. If your team needs something custom, [contact us](/contact) about custom development.

## How do I install a package?

Every package installs with a single Composer command, for example `composer require pharaonic/laravel-readable`. The exact command, requirements, and setup steps are on each package's page in the [catalog](/packages).

## Which PHP versions are supported?

Packages support PHP 7.2 and above. Each package's page lists its exact PHP requirement.

## Which Laravel versions are supported?

Laravel packages support Laravel 6.0 and above. Each package's page lists the exact Laravel versions it supports.

## How can I contribute?

Report bugs, suggest features, improve documentation, or open a pull request on any repository on [GitHub](https://github.com/pharaonic). Every contributor is listed on the [Contributors](/contributors) page and on the packages they helped build.

## Where can I get help or report a bug?

Open an issue on the package's GitHub repository, or ask in our [Discord](https://discord.gg/XQG9RhvEvf) community. You can also reach us through the [Contact](/contact) page.
