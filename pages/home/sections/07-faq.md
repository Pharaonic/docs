## What is Pharaonic?

Pharaonic is an open-source collection of {stats.packages} {stats.technologyList} packages, founded in 2020 by Moamen Eltouny (Raggi). Each package solves one common problem (files, images, slugs, translations, settings, Hijri dates, and more), so you can finish your project faster with less code.

## Are all packages free to use?

Yes. Every Pharaonic package is free and open source under {stats.licenseText}, so you can use it in personal and commercial projects. If your team needs something custom, [contact us](/contact) about custom development.

## How do I install a package?

Every package installs with a single Composer command, for example `composer require pharaonic/laravel-readable`. The exact command, requirements, and setup steps are on each package's page in the [packages](/packages).

## Which PHP versions are supported?

Current lines support PHP 8.1 – 8.5; each package lists the exact range for every line it maintains.

## Which Laravel versions are supported?

Each Laravel package has a line per Laravel major it supports, from its first one up to Laravel 13. A package's page lists every line with the PHP and Laravel versions that line's newest release needs.

## How can I contribute?

Report bugs, suggest features, improve documentation, or open a pull request on any repository on [GitHub](https://github.com/pharaonic). Every contributor is listed on the [Contributors](/contributors) page and on the packages they helped build.

## Where can I get help or report a bug?

Open an issue on the package's GitHub repository, or ask in [GitHub Discussions](https://github.com/orgs/Pharaonic/discussions). For a quick chat, join our [Discord](https://discord.gg/XQG9RhvEvf). You can also reach us through the [Contact](/contact) page.
